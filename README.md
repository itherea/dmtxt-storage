# dmtxt-storage

Esta data pertenece a una investigación sobre [hydra.ojack.xyz](https://hydra.ojack.xyz) y sus posibilidades para crear imagen en movimiento mediante código en tiempo real e intervenir dispositivos.

Período 2020 : 2026 · LIVE CODEADO POR UN SER HUMANO EN LA PATAGONIA ARGENTINA

## Galería

**[Ver la galería en vivo →](https://itherea.github.io/dmtxt-storage/)**

Cada sketch corre en el navegador con [hydra-synth](https://github.com/hydra-synth/hydra-synth). Podés editar el código en el momento, abrirlo en hydra.ojack.xyz, copiarlo o descargarlo.

- `Ctrl+Enter` ejecuta la línea, `Alt+Enter` el bloque, `Ctrl+Shift+Enter` todo.
- `Ctrl+Shift+H` oculta el código. `←` `→` pasan de sketch. `Esc` vuelve a la galería.
- Los sketches con **Audio** usan el micrófono (botón 🎤) y los de **MIDI** un controlador (`cc[]`).

Para verla en tu computadora sin internet para las imágenes: abrí `index.html` en el navegador.

## Usar un sketch

Copiá el contenido de cualquier archivo de [`sketches/`](sketches) y pegalo en [hydra.ojack.xyz](https://hydra.ojack.xyz). Algunos archivos tienen varias versiones una debajo de la otra: ejecutalas por bloque.

## Agregar sketches

1. Guardá el archivo como `sketches/NNN - Título.js` (por ejemplo `070 - Nuevo.js`).
2. Corré `python3 tools/generar.py` (actualiza la galería y la lista de abajo).
3. Opcional: `bash tools/miniaturas.sh 070` genera su miniatura.
